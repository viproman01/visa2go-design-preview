# Visa2Go design preview

Solution finder, compact application preview, interactive world map and synchronized train-window video. No applications are transmitted, no contacts are saved and no analytics is active on this public preview.

The catalogue editor at admin.html exports a configuration file. Server intake requires company details, verified services, final legal documents, a configured notifier and an authorized server deployment.

Only public static assets are deployed on this branch. Full implementation and tests: branch codex/visa2go-phase1, source commit bc574a48746d4b3c5c512efbc7fb4611780ef243.
